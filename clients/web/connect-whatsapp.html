This page is setup only. You chat in the WhatsApp app on your phone, not here.

Phone WhatsApp → ORCA

  1. Meta Developer → create an app → WhatsApp → Cloud API. Copy temporary access token and Phone number ID.
  2. Add your personal number as a recipient (Meta test numbers can only message allow-listed phones).
  3. Put this in .env: 
    ORCA_WHATSAPP_MODE=live
WHATSAPP_TOKEN=...
WHATSAPP_PHONE_NUMBER_ID=...
WHATSAPP_VERIFY_TOKEN=orca-dev
  4. Run the API: uvicorn orca.api.app:app --host 0.0.0.0 --port 8000
  5. Expose HTTPS (Meta cannot call localhost): 
    ngrok http 8000
    In Meta webhook: Callback URL https://YOUR-NGROK/webhooks/whatsapp, verify token orca-dev, subscribe to messages.
  6. On your phone, message the test business number Meta gave you (not a random contact).

Ask like the web demo, in text:

  • Where is the nearest fishing zone?
  • Is it safe to go out? cyclone
  • Is it safe to go out? kill weather
  • Share live location from WhatsApp

ORCA replies with text and, on a Mac with say, a voice note of the same guardrail-approved sentence. Inbound voice notes need Bhashini (ORCA_SPEECH_PROVIDER=bhashini); until then type the question.
